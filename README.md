## 🤖 What I build with AI

- **LLM provider layer:** one interface over **Anthropic Claude, OpenAI and Google Vertex AI**, so each feature picks the right model for its cost and quality.
- **RAG chatbot:** an in-app assistant that answers questions over the platform's own documents.
- **CV parsing:** reads resumes, extracts skills, experience and education, and pre-fills the candidate profile.
- **Matching engine:** ML scoring (scikit-learn) that ranks candidates against each job request.
- **Market-rate analysis:** an AI agent that estimates salary ranges for a role and location.
- **AI translation and summaries:** job postings translated EN ↔ ES and weekly digests written by an LLM, with safe fallbacks when the model fails.
- **WhatsApp bot:** candidates register by sending their CV through WhatsApp (Twilio).
- **AI-assisted development:** daily work with coding agents (Claude Code) for analysis, refactors, reviews and documentation.
